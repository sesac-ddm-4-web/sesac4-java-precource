# 모듈 7. 미니 과제: 숫자 야구 게임

A트랙 예상 2시간 · 코드 위치: [src/module07/](../src/module07)

> 모든 트랙 공통 과제입니다. 지금까지 배운 것(변수, 연산자, 조건문, 반복문, 메서드, 배열)을 전부 조합해서, 처음으로 프로그램 하나를 통째로 만들어봅니다.

## 게임 규칙

컴퓨터가 서로 다른 숫자 3개로 된 정답을 만들면, 사용자가 그것을 추리해서 맞히는 게임입니다.

- 숫자와 위치가 모두 맞으면 스트라이크(S)
- 숫자는 있는데 위치가 다르면 볼(B)
- 하나도 안 맞으면 낫싱

플레이 예시 (정답이 425일 때):

```
숫자 야구를 시작합니다. 서로 다른 숫자 3자리를 맞혀보세요.
입력: 678
낫싱
입력: 123
1스트라이크
입력: 456
1스트라이크 1볼
입력: 425
3스트라이크! 정답입니다.
시도 횟수: 4회
```

(123의 2는 정답의 가운데 자리와 위치까지 일치해서 스트라이크. 456의 4는 위치까지 맞아 스트라이크, 5는 숫자만 맞아 볼)

## 요구사항

필수:

1. 서로 다른 숫자 3개로 정답을 만든다. (첫 자리는 0이 아니어야 함)
2. 사용자에게 3자리 수를 반복해서 입력받는다.
3. 매 입력마다 결과를 출력한다. 둘 다 있으면 "1스트라이크 1볼", 하나만 있으면 "2볼"처럼 있는 것만, 둘 다 0이면 "낫싱".
4. 3스트라이크가 나오면 시도 횟수를 출력하고 종료한다.
5. 판정 로직은 별도 메서드로 분리한다. (main에 다 몰아넣지 않기)

선택 (필수를 끝낸 뒤에):

- 입력이 100~999 범위가 아닐 때 안내하고 다시 입력받기 (숫자가 아닌 입력까지 막고 싶다면 `scanner.hasNextInt()`로 먼저 확인하는 방법이 있습니다. 검색해보세요)
- 같은 숫자가 섞인 입력(예: 112) 거르기
- 게임이 끝나면 "다시 하시겠습니까?"를 물어 재시작하기

## 시작하기 전에: 필요한 도구 두 가지

**랜덤 숫자 만들기.** `Math.random()`은 0 이상 1 미만의 실수를 줍니다. 여기에 10을 곱하고 int로 변환하면 0~9의 정수가 됩니다.

```java
int digit = (int) (Math.random() * 10);   // 0~9 중 하나
```

"서로 다른 숫자 3개"는 어떻게 보장할까요? 한 가지 전략: 일단 3개를 뽑고, 겹치면 처음부터 다시 뽑기를 성공할 때까지 반복합니다. (while과 조건문의 조합) 첫 자리가 0인 경우도 같은 방식으로 다시 뽑으면 됩니다. 또는 첫 자리만 `(int) (Math.random() * 9) + 1`로 1~9에서 뽑는 방법도 있습니다.

**입력을 자릿수로 쪼개기.** 사용자가 425를 입력했다면:

```java
int hundreds = 425 / 100;        // 4
int tens = 425 / 10 % 10;        // 2
int ones = 425 % 10;             // 5
```

모듈 1의 W01(초를 시:분:초로)에서 쓴 그 기술입니다.

## 진행 순서 (권장)

한 번에 다 만들려고 하지 말고, 실행 가능한 상태를 유지하면서 한 단계씩 키우세요.

1. 정답을 만들어서 일단 화면에 출력해본다. (치팅용 출력. 완성하면 지운다)
2. 입력을 한 번 받아서 자릿수로 쪼개 출력해본다.
3. 판정 메서드를 만든다. 정답과 입력을 받아 스트라이크와 볼 개수를 센다.
4. 반복문으로 감싸서 3스트라이크까지 돌게 한다.
5. 시도 횟수를 세서 마지막에 출력한다.
6. (선택) 잘못된 입력 처리를 붙인다.

## 스스로 점검하기

완성했다고 생각되면 아래 시나리오를 직접 돌려보세요.

- [ ] 정답을 아는 상태(치팅 출력)에서, 일부러 1볼짜리 입력을 넣으면 정말 1볼이 나오는가
- [ ] 정답과 숫자 구성은 같고 순서만 다른 입력(예: 정답 425에 542)을 넣으면 3볼이 나오는가
- [ ] 첫 시도에 바로 맞히면 시도 횟수가 1회로 나오는가
- [ ] 여러 판을 해봐도 정답에 같은 숫자가 두 번 나오는 일이 없는가
