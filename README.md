# 자바 선수학습 (Pre-course)

SeSAC 백엔드 과정의 입과 전 필수 자율학습 자료입니다. JDK 21 기준으로 작성되었습니다.

**바로 시작하기**

1. 아래 "자가 진단"(1분)으로 내 트랙(A/B/C)을 정합니다.
2. [모듈 0](docs/00-setup.md)을 열어 환경을 셋업하고 첫 프로그램을 실행합니다.
3. 내 트랙의 학습 가이드 순서대로 진행합니다. 막히면 이 문서 맨 아래 "막혔을 때"를 보세요.

| 구분 | 내용 |
|---|---|
| 1차 목표 | 첫 수업 9/10(목) 전까지 모듈 0~5 (환경 셋업, 변수, 연산자, 조건문·반복문, 메서드, 클래스 기초) |
| 2차 목표 | 자바 문법 수업 9/12(토) 전까지 모듈 6~7 (배열, 숫자 야구) |
| 준비물 | 노트북(Windows 또는 Mac), 인터넷 (GitHub 계정은 모듈 0에서 만듭니다) |

일정이 빠듯해서 목표를 두 단계로 나눴습니다. 트랙 B·C는 분량이 적어 입과 전(9/6)에 마칠 수 있고, 트랙 A는 주말과 입과 직후 수업이 없는 날(9/8~9/9)을 활용하면 1차 목표까지 충분히 가능합니다.

이 자료의 목표는 자바를 끝내는 것이 아닙니다. 입과 후 첫 2주 수업(자바 문법, 컬렉션, 객체지향)을 편하게 따라갈 수 있는 상태를 만드는 것입니다. 여기서 다루는 내용은 입과 후 수업에서 모두 다시 다루므로, 지금 완벽하게 이해하지 못해도 괜찮습니다.

따로 제출할 것은 없습니다. 점수도 없습니다. 대신 입과 후 수업이 이 내용을 알고 있다는 전제로 진행되니, 자신을 위해 정직하게 진행해주세요.

## 2. 트랙별 학습 가이드

### 트랙 A: 기초 (자바가 처음이거나, 프로그래밍 자체가 처음)

모듈 0부터 7까지 순서대로 진행합니다. 모듈마다 문제 구성은 조금씩 다르므로, 각 모듈 문서 하단 "문제 풀기" 표에 있는 것만 순서대로 풀면 됩니다. 기본 흐름은 이렇습니다.

1. 문서(`docs/`)의 문법 설명을 읽고, 예제 코드(`ex/`)를 실행해봅니다.
2. 예측 문제(`predict/`)를 풉니다. 실행하기 전에 결과를 먼저 적는 것이 핵심입니다.
3. 그 모듈에 있는 버그 찾기(`trace/`), 변형(`modify/`), 작성(`make/`) 문제를 풉니다.
4. 학습 목표 체크리스트로 스스로 점검한 뒤 다음 모듈로 넘어갑니다.

권장 일정 (9/4 시작 기준):

| 날짜 | 진행할 모듈 |
|---|---|
| 9/4(금) | 모듈 0 (환경 셋업) |
| 9/5(토) | 모듈 1 (변수와 타입), 모듈 2 (연산자) |
| 9/6(일) | 모듈 3 (조건문과 반복문) |
| 9/7(월) | 입과, OT. 여유가 있으면 모듈 4 시작 |
| 9/8(화) | 모듈 4 (메서드) |
| 9/9(수) | 모듈 5 (클래스 기초). 여기까지가 1차 목표 |
| 9/10(목) | 첫 수업 |
| 9/10(목) 저녁, 9/11(금) | 모듈 6 (배열), 모듈 7 (숫자 야구). 여기까지가 2차 목표 |
| 9/12(토) | 자바 문법 수업 |

환경 셋업(모듈 0)은 첫날 끝내는 것을 목표로 하고, 오래 막히면 혼자 붙잡고 있지 말고 질문하세요. 9/8(화)~9/9(수)는 정규 수업이 없는 날이니 모듈 4~5를 진행하기 좋습니다.

### 트랙 B: 경험자 (다른 언어를 써봤거나, 자바를 배웠는데 가물가물)

전체를 다 읽을 필요는 없습니다. 입과 전(9/6)까지 마치는 것을 권장합니다.

1. 모듈 0에서 환경(JDK 21, IntelliJ, Git)만 맞춥니다.
2. 각 모듈 문서 상단의 "핵심 요약"을 읽습니다. 자바 특유의 동작(정수 나눗셈, 형변환, 참조와 null 등)에 특히 주의하세요.
3. 각 모듈의 `predict/` 문제만 풀어봅니다. 예측이 틀린 주제만 그 모듈의 문법 설명으로 돌아가서 확인합니다.
4. 모듈 7(숫자 야구)을 완성합니다.

### 트랙 C: 숙련 (자바로 개발해본 경험이 있음)

입과 전에 충분히 마칠 수 있는 분량입니다.

1. 환경(JDK 21, IntelliJ)을 맞춥니다.
2. 각 모듈의 `predict/` 문제를 빠르게 훑으며 예측해봅니다. 헷갈리는 것만 실행해서 확인하면 됩니다.
3. 모듈 7(숫자 야구)을 완성합니다. 금방 끝난다면 제약을 걸어보세요. 예를 들어 메서드를 3개 이상으로 분리하고 각 메서드가 한 가지 일만 하게 만들기.
4. 권장: 심화 과제(콘솔 계좌 관리)를 진행합니다. AI를 자유롭게 사용하는 대신 결과물을 스스로 검증하는 연습을 하는 과제로, 입과 후 다루게 될 "AI 산출물 검증"의 예습입니다. [docs/extra-bank.md](docs/extra-bank.md) 참고.

## 3. 학습 방법: 예측하고, 실행해서, 확인하기

이 자료의 문제 대부분은 코드를 짜는 문제가 아니라 코드를 읽는 문제입니다. 규칙은 세 줄입니다.

1. 실행하기 전에, 출력 결과를 예측해서 파일 주석의 "내 예측" 칸에 적는다.
2. 실행해서 예측과 비교한다.
3. 다르면 어디서 생각이 어긋났는지 한 줄 적는다. 예측이 틀린 순간이 가장 많이 배우는 순간입니다.

이렇게 구성한 이유가 있습니다. 앞으로 여러분이 마주칠 코드의 대부분은 남이(그리고 AI가) 쓴 코드입니다. 코드를 정확히 읽고 동작을 예측하는 능력이, 코드를 빨리 치는 능력보다 먼저입니다. 그렇다고 작성을 안 하는 것은 아닙니다. 모듈이 진행될수록 직접 쓰는 비중이 늘어나고, 마지막 숫자 야구는 처음부터 끝까지 직접 만듭니다.

## 4. AI 사용 가이드

AI를 쓰지 말라는 과정이 아닙니다. 잘 쓰는 연습을 지금부터 합니다.

| 이렇게 쓰세요 | 이렇게는 쓰지 마세요 |
|---|---|
| 셋업 에러 메시지를 통째로 붙여넣고 해결 방법 묻기 | 예측 문제의 답 묻기 (답은 실행하면 나옵니다) |
| 개념을 다른 비유로 설명해달라고 하고, 확인 퀴즈 요청하기 | 작성 과제와 숫자 야구를 통째로 생성시키기 |
| 모듈 4부터: 내가 짠 코드의 리뷰 요청하기 | |

질문 예시:

> IntelliJ에서 자바 파일을 실행하려는데 "SDK가 정의되지 않았다"고 나옵니다. JDK 21을 연결하는 방법을 메뉴 경로 순서대로 알려주세요.

> 자바의 while과 do-while 차이를 자판기에 비유해서 설명해줘. 그리고 내가 이해했는지 확인할 퀴즈 2개를 내줘. 답은 바로 알려주지 말고.

## 6. 저장소 구조와 사용법

```
├─ README.md            ← 지금 이 문서 (시작점)
├─ docs/                ← 모듈별 학습 문서 (읽는 곳)
└─ src/                 ← 코드 (IntelliJ에서 실행하는 곳)
   └─ module03/
      ├─ ex/            ← 개념 예제: 일단 실행해보기
      ├─ predict/       ← 예측하고 실행하기
      ├─ trace/         ← 버그 찾기
      ├─ modify/        ← 동작하는 코드 고쳐 만들기
      ├─ make/          ← 직접 작성 (실행해서 PASS가 뜨면 성공)
      └─ solutions/     ← 해설 (반드시 먼저 풀고 나서 열기)
```

`docs/`의 문서를 읽으면서 `src/moduleNN/`의 코드를 IntelliJ로 실행하는 흐름입니다. 문서 안의 파일 링크는 GitHub 웹에서 코드를 미리 보는 용도이고, 실제 실행은 clone 받은 내 컴퓨터의 같은 경로 파일을 IntelliJ에서 열어서 합니다. 저장소를 받아 IntelliJ에서 여는 방법은 모듈 0에서 안내합니다. `solutions/`는 먼저 풀어본 다음에 여세요.
