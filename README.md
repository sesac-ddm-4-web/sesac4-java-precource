# 자바 선수학습 (Pre-course)

SeSAC 백엔드 과정의 입과 전 필수 자율학습 자료입니다. JDK 21 기준으로 작성되었습니다.

| 구분 | 내용 |
|---|---|
| 기간 | 2026. 9. 6.(일) 23:59까지 |
| 이수 조건 | 체크포인트 폼 2개 제출 + 미니 과제(숫자 야구) 제출 |
| 준비물 | 노트북(Windows 또는 Mac), 인터넷, 구글 계정 (GitHub 계정은 모듈 0에서 만듭니다) |

이 자료의 목표는 자바를 끝내는 것이 아닙니다. 입과 후 첫 2주 수업(자바 문법, 컬렉션, 객체지향)을 편하게 따라갈 수 있는 상태를 만드는 것입니다. 여기서 다루는 내용은 입과 후 수업에서 모두 다시 다루므로, 지금 완벽하게 이해하지 못해도 괜찮습니다.

## 3. 트랙별 학습 가이드

### 트랙 A: 기초 (자바가 처음이거나, 프로그래밍 자체가 처음)

모듈 0부터 7까지 순서대로 전부 진행합니다. 각 모듈은 같은 구조입니다.

1. 문서(`docs/`)의 개념 설명을 읽고, 예제 코드(`src/moduleNN/ex/`)를 실행해봅니다.
2. 예측 문제(`predict/`)를 풉니다. 실행하기 전에 결과를 먼저 적는 것이 핵심입니다.
3. 버그 찾기(`trace/`), 변형(`modify/`), 작성(`make/`) 문제를 풉니다.
4. 해당 모듈의 체크포인트를 제출합니다.

권장 일정 (9/1 시작 기준):

| 날짜 | 진행할 모듈 |
|---|---|
| 9/1(화) | 모듈 0 (환경 셋업) |
| 9/2(수) | 모듈 1 (변수와 타입) |
| 9/3(목) | 모듈 2 (연산자), 모듈 3 시작 |
| 9/4(금) | 모듈 3 마무리, 모듈 4 (메서드) |
| 9/5(토) | 모듈 5 (클래스 기초), 모듈 6 (배열) |
| 9/6(일) | 모듈 7 (숫자 야구), 폼 제출 |

하루에 몰아서 하기보다 매일 2시간 안팎으로 나눠서 진행하는 편이 효과가 좋습니다. 환경 셋업(모듈 0)에서 오래 막히면 혼자 붙잡고 있지 말고 문의 채널을 이용하세요.

### 트랙 B: 경험자 (다른 언어를 써봤거나, 자바를 배웠는데 가물가물)

전체를 다 읽을 필요는 없습니다. 다음 순서로 진행합니다.

1. 모듈 0에서 환경(JDK 21, IntelliJ, Git)만 맞춥니다.
2. 각 모듈 문서 상단의 "핵심 요약"을 읽습니다. 자바 특유의 동작(정수 나눗셈, 형변환, 참조와 null 등)에 특히 주의하세요.
3. 각 모듈의 `predict/` 문제만 풀어봅니다. 예측이 틀린 주제만 그 모듈의 개념 설명으로 돌아가서 확인합니다.
4. 체크포인트 폼 2개를 제출하고, 모듈 7(숫자 야구)을 완성해 제출합니다.

### 트랙 C: 숙련 (자바로 개발해본 경험이 있음)

1. 환경(JDK 21, IntelliJ)을 맞춘 뒤, 체크포인트 폼 1과 2를 바로 풉니다.
2. 틀린 문항이 있으면 그 모듈의 `predict/` 문제로 짚고 넘어갑니다.
3. 모듈 7(숫자 야구)을 완성해 제출합니다. 금방 끝난다면 제약을 걸어보세요. 예를 들어 메서드를 3개 이상으로 분리하고 각 메서드가 한 가지 일만 하게 만들기.
4. 권장: 심화 과제(콘솔 계좌 관리)를 진행합니다. AI를 자유롭게 사용하는 대신 검증 리포트를 함께 제출하는 과제로, 입과 후 다루게 될 "AI 산출물 검증"의 예습입니다. [docs/extra-bank.md](docs/extra-bank.md) 참고.

## 4. 학습 방법: 예측하고, 실행해서, 확인하기

이 자료의 문제 대부분은 코드를 짜는 문제가 아니라 코드를 읽는 문제입니다. 규칙은 세 줄입니다.

1. 실행하기 전에, 출력 결과를 예측해서 파일 주석의 "내 예측" 칸에 적는다.
2. 실행해서 예측과 비교한다.
3. 다르면 어디서 생각이 어긋났는지 한 줄 적는다. 예측이 틀린 순간이 가장 많이 배우는 순간입니다.

이렇게 구성한 이유가 있습니다. 앞으로 여러분이 마주칠 코드의 대부분은 남이(그리고 AI가) 쓴 코드입니다. 코드를 정확히 읽고 동작을 예측하는 능력이, 코드를 빨리 치는 능력보다 먼저입니다. 그렇다고 작성을 안 하는 것은 아닙니다. 모듈이 진행될수록 직접 쓰는 비중이 늘어나고, 마지막 숫자 야구는 처음부터 끝까지 직접 만듭니다.

> IntelliJ에서 자바 파일을 실행하려는데 "SDK가 정의되지 않았다"고 나옵니다. JDK 21을 연결하는 방법을 메뉴 경로 순서대로 알려주세요.

> 자바의 while과 do-while 차이를 자판기에 비유해서 설명해줘. 그리고 내가 이해했는지 확인할 퀴즈 2개를 내줘. 답은 바로 알려주지 말고.

## 7. 저장소 구조와 사용법

```
java-precourse/
├─ README.md            ← 지금 이 문서 (시작점)
├─ docs/                ← 모듈별 학습 문서 (읽는 곳)
└─ src/                 ← 코드 (IntelliJ에서 실행하는 곳)
   └─ module03/
      ├─ ex/            ← 개념 예제: 일단 실행해보기
      ├─ predict/       ← 예측하고 실행하기
      ├─ trace/         ← 버그 찾기
      ├─ modify/        ← 동작하는 코드 고쳐 만들기
      ├─ make/          ← 직접 작성 (실행해서 PASS가 뜨면 성공)
      └─ solutions/     ← 해설 (반드시 먼저 풀고 나서 열기)
```

`docs/`의 문서를 읽으면서 `src/moduleNN/`의 코드를 IntelliJ로 실행하는 흐름입니다. 저장소를 받아 IntelliJ에서 여는 방법은 모듈 0에서 안내합니다. `solutions/`는 먼저 풀어본 다음에 여세요. 점수가 없으니 자신에게만 정직하면 됩니다.
